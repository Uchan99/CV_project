# Phase 0 — 데이터셋 통계 (BDD100K)

> 생성 스크립트: `scripts/prepare_bdd.py`
> 원본: BDD100K (100K Images + Labels), 이미지 해상도 1280×720
> 이 문서는 프로젝트의 문제 정의를 뒷받침하는 근거 데이터입니다.

## 데이터 규모

| Split | 이미지 수 | 박스 수 | 이미지당 평균 박스 |
|-------|-----------|---------|--------------------|
| train | 70,000 | 1,288,010 | 18.4 |
| val | 10,000 | 185,526 | 18.6 |

- test(20,000장)는 정답 라벨 비공개 → 사용하지 않음
- 평가는 **val 10,000장 고정**으로 수행
- attributes 누락 이미지: 0 (모든 이미지에 weather/timeofday 존재)
- 클래스 매핑 경고: 없음 (10개 클래스 전부 정상 변환)

## 시간대 분포 (timeofday) — 주 분석 축

| 조건 | train | val | 비고 |
|------|-------|-----|------|
| daytime | 52.6% | 52.6% | 주간 |
| **night** | **40.0%** | **39.3%** | **야간 — 핵심 분석 대상** |
| dawn/dusk | 7.2% | 7.8% | 새벽·황혼 |
| undefined | 0.2% | 0.4% | 제외 |

→ **야간이 val 기준 약 3,929장으로 충분하여, 조건별 mAP를 신뢰성 있게 측정 가능.**
→ train/val의 야간 비율이 거의 동일(40.0% vs 39.3%)하여 공정한 평가 조건.

## 날씨 분포 (weather) — 보조 분석 축

| 조건 | train | val | 평가 활용 |
|------|-------|-----|-----------|
| clear | 53.4% | 53.5% | 기준(맑음) |
| overcast | 12.5% | 12.4% | 흐림 |
| undefined | 11.6% | 11.6% | 제외 |
| snowy | 8.0% | 7.7% | ✅ 악천후 분석 |
| rainy | 7.3% | 7.4% | ✅ 악천후 분석 |
| partly cloudy | 7.0% | 7.4% | - |
| **foggy** | 0.2% | 0.1% | ❌ **val 13장뿐 → 평가 제외(참고용)** |

→ 악천후 분석은 **rainy(738장)·snowy(769장)** 중심으로 수행.
→ foggy는 표본이 너무 작아 mAP 신뢰 불가 → 조건별 평가에서 제외.

## 장면 분포 (scene) — 참고

| 조건 | train | 특징 |
|------|-------|------|
| city street | 62% | 객체 밀집(가려짐 문제) |
| highway | 25% | 원거리 소형 객체 문제 |
| residential | 12% | - |
| 기타 | 소수 | parking lot, tunnel, gas stations |

→ 주 분석 축은 아니나, 향후 "야간×고속도로" 교차 분석 여지 있음.

## 이 통계에서 확정된 프로젝트 방향

1. **주 분석 축 = timeofday (주간 vs 야간).** 야간 40%로 충분.
2. **보조 축 = weather의 rainy, snowy.** foggy는 제외.
3. **평가셋 = val 10,000장 고정.** 모든 실험에서 불변.
4. **핵심 지표 = day-night gap** (주간 mAP − 야간 mAP).
