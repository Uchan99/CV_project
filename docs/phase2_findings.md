# Phase 2 — 전이학습 깊이(freeze) 실험

> 목표: "8GB GPU 환경에서 사전학습 백본을 어디까지 동결(freeze)해야 하는가"를 정량 측정.
> 방법: freeze 값만 바꾸고 나머지(데이터·epoch·seed·batch) 고정 → 공정 비교.
> 공통 설정: YOLOv8s, 전체 train 70,000장, 30 epoch, imgsz=640, batch=16, seed=0

## 1. 실험 구성

| 실험 ID | freeze | 의미 |
|---------|--------|------|
| E2-1 | 0 | 백본 동결 없음 — 전체 레이어 파인튜닝 |
| E2-2 | 10 | 백본 앞 10개 레이어 동결 |
| E2-3 | 15 | 백본 대부분 동결 |
| E2-4 | 22 | 거의 head만 학습 |

- **주의:** freeze=0은 "from scratch(백지 학습)"가 아니라, COCO 사전학습 가중치에서 출발해 전체를 파인튜닝하는 것. 4개 모두 COCO 사전학습에서 시작하며, 차이는 "몇 개 레이어를 고정하느냐"뿐.

## 2. 핵심 결과

| 실험 | freeze | 전체 mAP50-95 | 주간 mAP50-95 | 야간 mAP50-95 | day-night gap |
|------|--------|---------------|---------------|---------------|---------------|
| E2-1 | 0 | **0.293** | 0.301 | **0.278** | **0.022** |
| E2-2 | 10 | 0.266 | 0.275 | 0.243 | 0.032 |
| E2-3 | 15 | 0.248 | 0.257 | 0.229 | 0.028 |
| E2-4 | 22 | 0.218 | 0.232 | 0.184 | 0.048 |

## 3. 발견

### 발견 1 — freeze를 늘릴수록 성능이 일관되게 하락
- 전체 mAP50-95: 0.293(freeze=0) → 0.218(freeze=22), 약 26% 하락.
- **해석:** BDD 주행 도메인은 COCO(일반 사진)와 충분히 달라, 백본을 고정하면 도메인 적응이 제한됨. 백본까지 다시 학습해야 성능이 나옴.

### 발견 2 — 백본을 동결할수록 야간이 주간보다 더 크게 무너짐
- freeze=0 → 22로 갈 때:
  - 주간: 0.301 → 0.232 (약 23% 하락)
  - **야간: 0.278 → 0.184 (약 34% 하락)**
- day-night gap: 0.022(freeze=0) → 0.048(freeze=22), 2배 이상 확대.
- **해석:** 야간 인지에 필요한 특징일수록 BDD 재학습에 의존. 백본 동결(=학습 제약)은 취약 조건(야간)을 먼저 희생시킴.
- **이 프로젝트 핵심 통찰과 연결:** "제약을 강하게 걸수록 야간이 먼저 무너진다"는 가설이 데이터로 확인됨. 이후 경량화(Phase 4~5)에서도 재현될 가능성 있음.

### 발견 3 — 자원 관점: 이 환경에선 freeze=0이 감당 가능
- freeze=0, batch=16에서 VRAM 약 3.95GB 사용 (8GB 중 절반 이하).
- 즉 "8GB라서 백본을 얼려야 한다"는 통념은 이 조합(YOLOv8s, 640px)에서는 불필요.
- 더 큰 모델·더 작은 GPU였다면 freeze가 필요했겠으나, 본 환경에선 전체 파인튜닝이 최적.

## 4. 결론 및 이후 방향

1. **이후 실험 기준 = freeze=0 (전체 파인튜닝).** 성능 최고 + 8GB에서 감당 가능.
2. **freeze는 성능을 희생하는 자원 절약책**임이 확인됨. 성능을 지키면서 자원을 아끼는 정교한 대안은 **PEFT/LoRA 트랙**에서 다룰 예정(별도 ViT 기반 실험).
3. Phase 3(데이터 전략)은 freeze=0을 고정하고 데이터만 조정해 야간 gap 축소를 시도.

## 5. 방법론 메모
- 4개 학습을 `run_phase2.sh`로 순차 자동 실행(nohup 백그라운드), 각 학습 독립 → 하나 실패해도 나머지 진행.
- 평가는 `eval_by_condition.py`로 조건별 측정, `experiments.csv`에 누적.
