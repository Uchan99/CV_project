# Phase 1 — 문제 정량화 및 야간 실패 분석

> 목표: "야간·악천후에서 인지 성능이 저하된다"는 문제가 실재함을 정량적으로 증명하고,
> 그 저하의 구체적 원인을 규명한다.
> 평가셋: BDD100K val 10,000장 (고정) · 모델: YOLOv8s

## 1. 실험 구성

| 실험 ID | 내용 | 목적 |
|---------|------|------|
| E1-0 | COCO 사전학습 모델 zero-shot 평가 (파인튜닝 없음) | 도메인 갭의 출발점 |
| E1-1 | BDD 학습 baseline (YOLOv8s, 50 epoch) | 학습 후 기준 성능 |

- zero-shot은 COCO↔BDD가 겹치는 7개 클래스만 매핑해 근사 비교 (car, person↔pedestrian, bus, truck, bicycle, motorcycle, traffic light)
- 모든 평가는 조건별(주간/야간/우천)로 분리 측정

## 2. 핵심 결과 — day-night gap

| 시점 | 주간 mAP50-95 | 야간 mAP50-95 | gap | 야간/주간 비율 |
|------|---------------|---------------|-----|----------------|
| **E1-0 (zero-shot)** | 0.219 | 0.147 | **0.072** | 67% |
| **E1-1 (baseline)** | 0.308 | 0.285 | **0.023** | 93% |

### 해석

1. **야간 문제는 실재한다.** COCO 사전학습 모델은 야간에서 크게 무너진다(야간이 주간의 67% 수준). 일반 모델이 야간 도메인에 취약함을 정량 확인.
2. **도메인 학습이 격차를 상당히 메운다.** BDD 파인튜닝으로 gap이 0.072 → 0.023으로 축소(야간이 주간의 93%까지 회복).
3. **그러나 격차는 여전히 남아 있다.** baseline에서도 야간이 주간보다 0.023 낮음. → 이 잔여 격차가 Phase 2·3의 개선 목표.

## 3. 날씨 조건별 성능 (baseline 기준)

| 조건 | mAP50-95 | n |
|------|----------|-----|
| clear | 0.291 | 5,346 |
| rainy | 0.304 | 738 |
| snowy | 0.278 | 769 |

- **snowy가 가장 어려움** — 노면·배경이 하얗게 뭉개져 대비 저하.
- rainy가 clear보다 높게 나온 것은 의외 — 비 장면이 주로 주간·도심에 분포한 영향으로 추정.
- foggy는 val 13장뿐이라 평가에서 제외.

## 4. 야간 실패 케이스 분석 (정성)

baseline 모델을 야간 이미지에 적용, 예측(초록) vs 정답(빨강)을 대조.

### 관찰된 지배적 실패 유형

**① 원거리 소형 객체 놓침 (주요 원인)**
- 멀리 있어 작고 어두운 차량·보행자를 탐지하지 못함
- 예: 한 장면에서 정답 16개 중 8개만 검출(-8), 어둠에 묻힌 원거리 주차 차량 다수 누락
- 근거리 대형 객체(car conf 0.90+)는 야간에도 안정적으로 검출 → 문제는 "야간" 자체보다 "야간 × 원거리 소형"의 교집합

**② 강한 광원 주변의 혼란**
- 헤드라이트·간판·가로등 불빛이 번지는 영역에서 놓침과 헛박스가 동시 발생
- 밝은 창문·조명을 traffic light 등으로 오인하는 false positive 관찰
- 주간에는 드문, 야간 특유의 문제

**③ 극저조도 장면에서의 전면적 저하**
- 광원이 거의 없는 칠흑 장면에서는 원거리 객체를 낮은 confidence(0.26 등)로 겨우 잡거나 완전 누락
- 사람 눈으로도 식별이 어려운 수준의 저조도가 성능 하락의 물리적 한계로 작용

### 실패의 분산

- 야간 저하는 균일하지 않고 **장면에 따라 편차가 큼** (동일 조건 내 -8 놓침 ~ +5 헛박스 공존)
- 평균 gap(0.023) 이면에 큰 이미지별 분산이 존재 → 특정 장면 유형(저조도·원거리 밀집)에서 집중적으로 실패

## 5. Phase 2·3 개선 가설

실패 분석에서 도출한 방향:

1. **해상도 상향** — 원거리 소형 객체가 주된 실패 원인이므로, 입력 해상도를 높이면(작은 객체가 상대적으로 크게 보임) 놓침이 줄어들 것으로 예상.
2. **야간 데이터 전략** — 야간 오버샘플링·야간 특화 증강(밝기·대비·노이즈)으로 야간 취약성 완화 기대.
3. **검증 방법** — 개선 후 동일한 조건별 평가 + 실패 케이스 분석을 반복해, day-night gap 축소와 원거리 소형 객체 검출 개선을 정량·정성 양면으로 확인.
