# Phase 3 — 데이터 전략 실험 (야간 gap 축소)

> 목표: 모델·자원을 늘리지 않고 **데이터 구성만 조정**해 야간 성능 저하(day-night gap)를 줄일 수 있는가.
> 방법: freeze=0 고정, 데이터 구성/증강만 변경.
> 공통 설정: YOLOv8s, 30 epoch, imgsz=640, batch=16, seed=0, freeze=0
> 기준(E3-1) = Phase 2의 E2-1_freeze0 (재실행 없이 비교 기준으로 사용)

## 1. 실험 구성

| 실험 ID | 전략 | 방법 |
|---------|------|------|
| E3-1 (기준) | 없음 | E2-1_freeze0과 동일 |
| E3-2 | 야간 오버샘플링 x2 | 야간 이미지를 학습 목록에 2배 포함 (야간 비중 40%→57%) |
| E3-3 | 야간 특화 증강 | hsv_v=0.6, hsv_s=0.8, hsv_h=0.02 (밝기·채도 변화 강화) |
| E3-4 | 오버샘플링 + 증강 | E3-2 + E3-3 조합 |

## 2. 핵심 결과

| 실험 | 전체 mAP50-95 | 주간 | 야간 | **day-night gap** |
|------|---------------|------|------|-------------------|
| E3-1 (기준) | 0.293 | 0.301 | 0.278 | 0.022 |
| E3-2 오버샘플링 | 0.292 | 0.298 | 0.283 | **0.015** |
| E3-3 증강만 | 0.294 | 0.301 | 0.279 | 0.022 |
| E3-4 조합 | 0.292 | 0.297 | **0.286** | **0.011** |

## 3. 발견

### 발견 1 — 데이터 전략으로 gap을 절반으로 축소
- 기준 gap 0.022 → E3-4 조합 gap 0.011 (약 50% 축소).
- **주간을 거의 희생하지 않고 야간만 상승**: E3-4에서 야간 0.278→0.286(+0.008), 주간 0.301→0.297(-0.004).
- 전체 mAP는 0.293으로 거의 불변 → 모델·자원 증설 없이 취약 조건만 개선.
- **의의:** 실무에서 가장 저비용 개선 수단(데이터 전략)의 효과를 정량 입증.

### 발견 2 — 오버샘플링은 효과, 증강 단독은 무효
- E3-2(오버샘플링): gap 0.022 → 0.015 (효과 있음)
- E3-3(증강만): gap 0.022 → 0.022 (변화 없음)
- **해석:** "진짜 야간 데이터를 더 자주 보는 것"이 "이미지를 인위적으로 어둡게 변형하는 것"보다 효과적. hsv 증강이 만든 인위적 어둠은 실제 야간 특성(헤드라이트 번짐·극저조도·원거리 소형 객체)을 재현하지 못한 것으로 추정.

### 발견 3 — 증강은 단독으론 무력하나 오버샘플링과 결합 시 소폭 기여
- E3-2(0.015) → E3-4(0.011)로 조합 시 약간 더 축소.
- 단, 차이가 작아 노이즈 가능성 있음 → 단정하지 않음.

## 4. Phase 1~3 통합 — gap의 여정

| 단계 | 상태 | day-night gap |
|------|------|---------------|
| E1-0 | zero-shot (학습 안 함) | 0.072 |
| E1-1/E2-1 | freeze=0 학습 | 0.022 |
| E2-4 | freeze=22 (백본 동결) | 0.048 |
| **E3-4** | **오버샘플링+증강** | **0.011** |

→ "일반 모델은 야간 취약(0.072) → 도메인 학습이 메움(0.022) → 백본 동결 시 악화(0.048) → 데이터 전략으로 추가 축소(0.011)"의 완결된 서사.
→ Phase 1에서 세운 개선 가설("야간 데이터 강화")이 Phase 3에서 실증됨.

## 5. 결론 및 이후 방향
- **최종 성능 모델 = E3-4** (야간 gap 최소 0.011 + 전체 성능 유지).
- 이 모델이 Phase 4~5(경량화·양자화·배포)의 대상.
- 다음 단계: 성능을 지키면서 실시간 요구(FPS)를 만족시키는 최적화.

## 6. 방법론 메모
- 오버샘플링: 학습 이미지 목록(txt)에 야간 경로를 중복 삽입 (`prepare_phase3.py`).
- val(평가셋)은 전 실험 고정 → 조건별 비교 공정성 유지.
- 3개 실험 순차 자동 실행(`run_phase3.sh`, nohup). 스크립트 내 venv 활성화로 nohup 환경에서도 yolo 인식.
